Forever AddOn Manager

Addons marked CurseForge only can only be downloaded on the CurseForge website, by their author's choice. Download the zip there, then drag it onto this window or install it on the tab. The app still tracks and checks them for updates.

    Installs the latest GitHub release if there is one, otherwise the default branch. Add /tree/<branch> to the URL to follow a branch. Other Git hosts are cloned.

      Installs an addon from a zip (for example one downloaded from CurseForge) or copies an addon folder into AddOns. You can also drag zips onto this window. Zips CurseForge recognises are tracked as CurseForge addons and checked for updates; everything else can be reinstalled from its file on the Installed tab.
